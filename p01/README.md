# Student Scores Dataset

This project contains a dataset named `student_scores.csv` located in the `dataset/` directory.

## Dataset Description

The `student_scores.csv` file contains data related to students and their scores. This dataset can be used for tasks such as regression analysis, data visualization, and machine learning model training.

### Example Structure

| StudentID | Name      | Score |
|-----------|-----------|-------|
| 1         | Alice     | 85    |
| 2         | Bob       | 78    |
| ...       | ...       | ...   |

*Note: The actual columns may vary. Please open the CSV file to see the exact structure.*

## Usage

1. Install dependencies from `requirements.txt`:
    ```sh
    pip install -r requirements.txt
    ```

2. Load and analyze the dataset using Python or Jupyter notebooks.

## Environment

A Python virtual environment is provided in the `p01_env/` directory. Activate it before running any scripts:
- On Windows:
    ```sh
    p01_env\Scripts\activate
    ```
- On Unix or MacOS:
    ```sh
    source p01_env/bin/activate
    ```
